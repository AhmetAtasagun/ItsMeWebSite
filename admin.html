// GitHub Direct Deploy Ayarları

Web üzerinden tek tıkla canlıya almak için Personal Access Token (PAT) girin

🔒 Güvenlik: Token bilgisi yalnızca tarayıcınızın yerel belleğinde (localStorage) saklanır, hiçbir harici sunucuya iletilmez.
🔑 Gereken İzinler:
• Classic Token (ghp_...): repo kutucuğu işaretli olmalıdır.
• Fine-grained Token (github_pat_...): Depo seçilip Repository Permissions > Contents > Read and write izni verilmelidir.
